Entity Arrows

Untangle the arrows. Free every string in order.

Coming soon to Google Play Join the beta (Android) How to join the beta Privacy policy

About the game

Each level is a board of tangled arrow-shaped strings. Tap a string to slide it free - but only if nothing blocks the path ahead of its arrowhead. Clear the whole board in the right order to finish the level.

How to play

  1. Look at where each arrow's head is pointing.
  2. Tap a string whose path to the edge is clear - it slides off the board.
  3. If a string is blocked, it shakes and the string in its way lights up.
  4. Free every string to complete the level.

Features

  • 250 levels, grouped in ranges of 25
  • 3-star rating per level based on wrong taps
  • Up to 3 hints per level that highlight a string free to move
  • Daily streak: complete 10 levels in a day to keep it going
  • Close the app mid-puzzle and carry on where you left off
  • System, Light or Dark theme
